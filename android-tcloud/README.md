# T-Cloud Android

既存の T-Cloud Storage と同じ Cloudflare Worker・D1・R2・認証・暗号化データを利用する、Androidネイティブアプリです。WebViewでWeb版を包む構成ではありません。

## 名称と対応範囲

- 正式サービス名: `T-Cloud Storage`
- Androidのアプリ表示名: `T-Cloud Player`
- パッケージ名: `jp.tanaka.tcloud`
- 対応OS: Android 8.0（API 26）以降
- 対象SDK: Android 16（API 36）
- アプリ版: `1.4.1`（versionCode 32）

Android 8.0まで対応範囲を広げつつ、API 36を対象にして新しいAndroidのセキュリティ要件へ対応します。

### 1.4.1 Visual Experience 2.0 Player修正

- Local／T-Cloud音楽を選ぶと、既存キューの開始後にアートワーク中心のNow Playingを表示
- Now Playingの再生、シーク、前後移動、シャッフル、リピートは一覧側と同じPlaybackManagerへ接続
- 写真のCrop／Fitと角丸差はShared Bounds内でfadeし、開閉時の急な見た目の切替を抑制

### 1.4.0 T-Cloud Visual Experience 2.0

- Material 3を基盤に、端末のライト／ダーク設定とAndroid 12以降のDynamic Colorへ追従
- edge-to-edgeとWindow Size Classを採用し、スマートフォンの回転やタブレット等の画面幅へ適応（ヒンジ位置を使う専用2ペインレイアウトではありません）
- Storageは画面幅に応じた2〜4列表示と、拡張幅でのNavigation Railを提供
- Playerは音楽のアートワーク中心表示から既存の再生キューを直接操作し、動画の没入表示、既存のMedia3／YouTube公式Player操作を両立
- フォルダ階層、選択、フィルター、音楽／動画切替に一貫した短いモーションを適用
- 予測型Back、選択時の触覚フィードバック、IMEリサイズ、48dp以上の操作領域を共通方針として適用

音楽Now Playingは一覧側と同じ`TCloudPlaybackManager`／`ExoPlayer`を利用します。認証、権限、暗号化・復号、通信、D1/R2、データモデル、検索・おすすめ、再生・保存ロジックは1.3.0から変更していません。動画をCloudflare側へ平文で渡さない原則も維持します。

### 1.3.0 Visual / Motion refresh

- StorageとPlayerで共通の色・余白・角丸・タイポグラフィ・モーション規則を採用
- フォルダ／ファイル一覧を、強い枠線ではなく余白とtonal surfaceで整理する表示へ刷新
- フォルダ階層の前進／後退、Storage／Player切り替え、選択・並び替え・絞り込みへ短い自然なモーションを追加
- 検索、フィルター、Empty State、ローディング、メディアキューの視覚階層を統一

暗号化・復号、認証、通信、データモデル、T-Cloud／YouTube／端末メディアの機能仕様は1.2.0から変更していません。

## 実装済みの基盤

- 既存T-Cloudアカウントの認証証明を端末内で生成
- HttpOnlyセッションCookieの暗号化保存とログイン復元
- 管理者秘密鍵の端末内復号
- 副管理者のフォルダPW認証と30日間の端末内鍵保護
- 既存フォルダ・ファイル一覧の取得
- 既存Web版と同じ方式によるファイル名等の復号
- 複数ファイルの手動選択アップロード
- 端末内暗号化と既存R2マルチパートAPIへの送信
- 暗号チャンクのバックグラウンドダウンロードと端末内復号
- 通知欄での転送進捗表示と中止
- R2の暗号化チャンクを復号せず保存する30日間のオフライン保存
- 端末保存済みチャンクを優先利用するMedia3動画・音楽再生
- FLVを明示認識するMedia3再生と、次チャンク先読み
- 端末メモリに応じた32〜128MBの再生専用LRUキャッシュ（終了時に平文を消去）
- 端末内だけで復号する画像表示、ピンチ拡大、移動表示
- 解除済みフォルダだけを対象にした端末保存一覧と個別削除
- 管理者の全フォルダおよび副管理者の解除範囲内における単一ファイル移動
- 移動先に合わせたファイル鍵の再ラップ（R2ファイル本体の再送信なし）
- ファイル名の端末内再暗号化とフォルダ名変更
- 単一フォルダ移動と移動先親鍵へのフォルダ鍵再ラップ
- 管理者・副管理者による単一ファイル／フォルダの共有URL発行
- 強固な共有PW生成、有効期限設定、URL・PWの個別／一括コピー
- 長押しによるファイル・フォルダの複数選択
- 選択中の再タップによる個別解除、戻る操作による選択解除、すべて選択
- ファイル・フォルダ混在の一括移動と、最大100ファイルの一括共有
- 複数ファイルの一括ダウンロードと暗号化オフライン保存
- 選択したファイル・フォルダの確認付き一括削除
- 管理者はゴミ箱移動、副管理者にはゴミ箱を開示しない既存削除権限の維持
- クラウド削除に連動した該当端末保存データの削除
- バッテリー最適化除外の状態確認とAndroid公式許可画面への導線
- 明示指定したフォルダへのカメラロール自動バックアップ
- 初期無効、新規写真・動画のみ、端末フォルダ別、従量課金なし通信限定・充電中のみの個別設定
- 自動バックアップの差分カーソル、続きからの走査、完了履歴、失敗分の自動再試行
- Web版と同じ既定順とフォルダ別の並び順記憶
- 横長／1:1表示を1つのボタンで切り替え、フォルダ別に記憶
- フォルダPWの変更と副管理者の再ロック
- 動画のピクチャーインピクチャと、端末内復号を維持するAndroid標準のテレビ画面共有
- Android KeystoreによるCookie・アカウント鍵・フォルダ鍵の保護
- HTTPS以外の通信拒否
- アプリデータのOSバックアップ禁止
- Storageトップの再生アイコンから開く専用Playerライブラリ
- MediaStoreの端末音楽・動画と、実際に解除したT-Cloudフォルダ配下の音楽・動画を共通索引へ差分反映
- 端末SQLite索引の即時表示、端末／T-Cloud／YouTubeの横断検索と保存元絞り込み
- 曲・アーティスト・アルバム・最近再生・お気に入り・あとで見る・混在プレイリスト
- 端末とT-Cloudを混在できる音楽キュー、シャッフル、全体リピート、1曲リピート
- Local／T-Cloudの索引とYouTube Data APIを横断するキーワード検索、YouTube URL／video IDのリンク保存、公式IFrame Playerによる再生、履歴・お気に入り・プレイリスト
- 端末内の再生傾向に基づく「T-Cloud Playerのおすすめ」と、TTLキャッシュ付きYouTube候補取得

YouTube動画はダウンロード・録画・R2保存せず、公式埋め込みPlayerだけで再生します。YouTube Data APIキーはAPKやGitHubへ含めず、Cloudflare Worker Secret `YOUTUBE_API_KEY` として設定します。Secret未設定時もYouTube URL保存と公式再生、Local／T-Cloudライブラリは利用できますが、オンラインのタイトル取得と新規おすすめ検索は設定完了まで利用できません。

本番のAPIキーはGoogle CloudでYouTube Data API v3だけを利用可能に制限したサーバー用キーを作成し、リポジトリへ書かずに`cloud-worker`で`pnpm exec wrangler secret put YOUTUBE_API_KEY`を実行して登録します。埋め込み再生はAndroid標準WebView内の公式IFrame Player APIを使い、ホストページの`origin`を`https://tanaka-note.com`へ固定します。

パスワード、平文ファイル、復号鍵をCloudflareへ送信しません。署名鍵とパスワードもリポジトリへ保存しません。

## ビルド

JDK 17とAndroid SDK 36を使用します。ローカルのSDKパスは、Git管理外の `local.properties` へ設定します。

```powershell
./gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleRelease
```

署名設定はGit管理外の `keystore.properties` から読み込みます。署名鍵を紛失すると、同じアプリとして更新できなくなるため、鍵と復旧情報は別の安全な場所にも保管してください。

バッテリー最適化除外、通知、写真・動画へのアクセスは利用者がAndroidの許可画面で承認します。アプリはOS設定を無断で変更しません。
